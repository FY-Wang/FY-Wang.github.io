# FY-Wang.github.io

Personal research website for Fengyi Wang, hosted with GitHub Pages.

The first version presents the project page for:

> F. Wang, J. R. Guadarrama-Olvera, and G. Cheng, “Optimal Order Pick-and-Place of Objects in Cluttered Scene by a Mobile Manipulator,” *IEEE Robotics and Automation Letters*, 6(4), 6402–6409, 2021.

## Update the website

- Edit `index.html` to change text, links, or page sections.
- Edit `styles.css` to change colors, typography, spacing, or responsive layout.
- Commit changes to the `main` branch. GitHub Pages will republish the website automatically.

## Publication policy

This repository contains an author-provided project page. It does not host the IEEE version of record. Code, data, images, and manuscripts should only be added after their licenses and redistribution rights have been checked.
