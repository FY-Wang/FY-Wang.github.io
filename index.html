Overview

Planning manipulation and navigation together

A mobile manipulator in a cluttered scene must solve more than an object-ordering problem. A target may only be reachable from certain base poses, those poses may be blocked, and stacked objects introduce additional dependencies between actions.

This work combines grasp–base sampling, dependency reasoning, goal arrangement, and route optimization in one planning pipeline. The resulting plan handles both monotone tasks and cases that require temporary buffer moves.

Core contributions

01

Reason about feasibility

Infer manipulation preconditions from robot kinematics, candidate base placements, and objects that temporarily block access.

02

Resolve dependencies

Represent ordering constraints with a dependency graph and introduce buffer actions when a direct monotone sequence is impossible.

03

Optimize the route

Transform feasible grasp and placement choices into a pickup-and-delivery routing problem that minimizes robot base travel.

Reported results

Fast planning with less robot travel

Selected results reported in the paper. Public code, benchmark data, and regenerated figures will be added as the research artifact is prepared.

17% up to 17% less base travel in monotone experiments
25% lower total execution time in the non-monotone example
≈ 9 s whole planning pipeline for a 20-object scene
